# Student Data Analysis Using Python

A beginner-friendly data analysis project built using Python and Pandas to analyze student marks, calculate performance statistics, and generate student rankings.

## Project Overview

This project reads student records from a CSV file, analyzes their marks, identifies high-performing students, and generates a ranking report. It demonstrates fundamental data analysis concepts using Python.

##  Features

-  Read student records from a CSV file
-  Calculate average, highest, and lowest marks
-  Identify students scoring above 80 marks
-  Rank students according to their marks
-  Export student rankings to a CSV file
-  Validate input data and required columns
-  Generate sample data if the input CSV is missing

##  Technologies Used

- **Python** — programming language
- **Pandas** — data manipulation and analysis
- **CSV** — data storage and export

##  Installation

### 1. Install Python

Install Python 3 from the official website:

https://www.python.org/downloads/

### 2. Download the Project

Clone the repository:

```bash
git clone https://github.com/Amishkumarchanchal/student-data-analysis.git
cd student-data-analysis
```

Alternatively, download the repository as a ZIP file from GitHub and extract it.

### 3. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

##  How to Run

Run the following command from the project directory:

```bash
python student_analysis.py
```

The program displays student records, calculates summary statistics, identifies students scoring above 80, and prints the student ranking.

##  Output

After successful execution, the program generates:

- **`student_ranking.csv`** — student records sorted by marks, including their ranks.

The output file is saved in the same directory as the Python script.
